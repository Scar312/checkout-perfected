# Checkout Perfected

Your task is to create a pixel-perfect, fully functional replica of the checkout flow shown in the attached screen recording.

The final result must match the original as closely as possible in every visual and interactive detail, including but not limited to:

Layout and spacing

Typography (font family, weight, size, letter spacing, and line height)

Colors, gradients, shadows, and borders

Icons and PNG assets

Animations, transitions, loading states, and micro-interactions

Button styles and hover/pressed/focus states

Element sizing, positioning, padding, and margins

Responsive behavior (if visible in the recording)

Assets

Recreate all images and icons as accurately as possible.

If an image or PNG asset cannot be recreated with sufficient accuracy, extract it directly from the screen recording (or screenshots) and use it instead.

Every visual asset should closely match the original.

Promo Code Functionality

Use the following GitHub repository as the reference implementation for the promo code logic:

https://github.com/Scar312/checkout-delight-replica.git

Replicate the promo code functionality exactly, including:

Applying valid promo codes.

Dynamically updating all prices, discounts, totals, and any affected values.

Allowing users to type and submit promo codes.

Displaying the appropriate success state when a valid code is entered.

Displaying the same error behavior and messaging when an invalid or unsupported promo code is entered.

Matching the validation flow and calculations from the GitHub repository.

UI + Functionality Integration

The visual design must match the attached screen recording, while the promo code behavior and business logic should match the GitHub repository.

The end result should feel indistinguishable from the original checkout experience, with the appearance taken from the recording and the promo code functionality taken from the repository.

Do not simplify, approximate, or redesign any part of the interface. Replicate every visible detail and interaction as faithfully as possible.
